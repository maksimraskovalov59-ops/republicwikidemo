# RepublicMC Article Forge

Создай страницу статьи для википедии RepublicMC WIKI в точно таком же стиле, как главная страница.

Стиль:

- Тёмный фон (глубокий тёмно-синий/чёрный)

- Мелкие цветные пиксели (циановые, синие, розовые, фиолетовые) на фоне

- Акцентные цвета: яркий циан → синий и розово-пурпурный (как в логотипе REPUBLICMC)

- Современный чистый интерфейс с мягким свечением

- Карточки с полупрозрачным тёмным фоном и тонкой обводкой

Структура страницы статьи:

1. Верхняя шапка (такая же, как на главной):

   - Логотип REPUBLICMC WIKI слева

   - Навигация справа: Правила, Карта сервера, Дискорд, Кабинет

2. Основная зона (две колонки):

Левая узкая колонка:

- Оглавление статьи (Contents) — список разделов с якорными ссылками

- Блок «Категории» статьи

- Блок «Последние изменения» этой статьи

Правая широкая колонка (основной контент):

- Заголовок статьи крупным шрифтом

- Под заголовком: дата последнего редактирования + автор + количество просмотров

- Кнопки: Редактировать | История | Обсуждение (только для авторизованных/админов)

- Основной текст статьи с подзаголовками, списками, цитатами

- Возможность вставки изображений

- Внизу статьи: блок «См. также» и «Категории»

Дизайн должен полностью совпадать по атмосфере, цветам, шрифтам и стилю карточек с главной страницей RepublicMC WIKI.

Сделай страницу полностью рабочей и адаптивной.
